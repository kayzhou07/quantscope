# 量化一｜当前策略、历史最高收益与低换手复盘

更新：2026-10-19。本文按Tang最新纠正，将“最多每月调仓一次、最好全年3—4次，买后尽量不动”作为当前目标，替代此前约100笔成交／年。**最新已保存到平台并完成回测的是v8Q季度版；不是v6b，也不是旧的日线均线退出版。**

## 一、结论先看

减少操作已实际做到：2026-04-01至平台最近可用2026-10-16，季度版只有4月1日、7月1日、10月8日三个交易日期，合计15笔成交，收益−0.02%、最大回撤5.84%。全年四个季度的规则不等于已完成全年回测；本轮只验证这段区间。

“因子过多制造噪声”目前不是已经证实的亏损原因。新版选股分数已经只有一个月线动量；财务、行业、投票情绪、EM／SPY、silent momentum等未参与评分。已有证据更直接指向：资金过滤改变了实际买到的股票、多个风险预算压低仓位、旧版短周期卖出，以及个别持仓行情与起止日期变化。

早期记录中出现过最高50.65%的含科创板编辑器试跑；当前正式、可重新打开核验的最高结果是排除未确认权限板块后的18.19%。两者不能混成一份成果，也不能据此挑最高数字作为预期收益。

## 二、现在的策略究竟做什么

| 环节 | 当前v8Q规则 |
|---|---|
| 股票池 | 信号时点历史沪深300成分，排除688／689科创板；不是全A股票池 |
| 选股 | 完整月线12−1动量，P_(m−1)/P_(m−12)−1，权重100%；最多4只，资金可行性递补 |
| 调仓 | 每年1、4、7、10月首个交易日；使用上一个完整月及更早数据，开盘尝试执行 |
| 两次调仓之间 | 不下新订单；取消日MA5减半、MA13／30清仓、每日目标恢复和每日现金修正 |
| 持有期 | 普通持仓以跨季度为目标；不再以7交易日为核心轮换条件。未成交不跨日无限追单 |
| 仓位 | 只在季度调仓时估计波动与风险预算；20%目标年化波动研究值，不加杠杆，仍叠加单股、Beta、残差及尾部预算 |
| 现金与宏观 | 密歇根通胀和缩量防守只在季度复核。通胀≥4%时目标风险资产上限70%；缩量触发时红利ETF目标50%。季度间可能漂移，不再声称每日强制现金下限 |
| 资金可行性 | 暂保留旧200股加10元费用不得超过资产4%的候选门槛；这不是价值因子，会偏向名义股价低的证券，且如今无半仓卖出需求，后续需单独检验是否保留 |
| 斐波那契 | 23.6%、38.2%、50%、61.8%已在平台实际计算并记日志；包含上影线的月high为高点，24月窗口、最近12月找高点，低点严格在高点月之前。反弹检验用前月冻结线位；仍为观察项，尚未直接触发买卖 |
| 其他因子 | 行业／广度／财务／情绪等候选不计分；未确认定义或无历史数据的项目不伪装为已接入 |

季度版不是仅把v7A日历改为三个月：还取消了日均线入场／退出与每日干预，宏观／缩量复核同步降频。因此版本差异属于联合改动，不能全部归因于单个因素。当前尚未逐项消融。

本轮所有四组基准均为−6.28%。策略不会把基准“做差”：代码只指定基准，基准由指数行情与日期决定。

## 六、历次结果为什么看上去总在下降

不同期间先分开：5月至10月16日，v1为+2.19%／回撤29.82%，v2为−0.50%／2.76%，v3为−5.05%／5.95%，v4为−1.04%／2.05%；该期间基准−13.24%。另一个一年期2025-10-17至2026-10-16，v5为−0.04%／0.84%（5笔），v6为−7.65%／10.78%（401笔），v6b为−5.99%／6.13%（142笔），同期基准−9.70%。这些不能与本次4月至10月结果混排成一张“越来越差”的排行榜。

1. **收益目标与风险目标不同。** 最初高集中、较大持仓风险，可以抓到个股大涨，也承受大回撤；后续为控制风险持有更多现金。不能同时要求保留原来的收益并默认风险必然降低。
2. **买到的股票已变。** v8Q季度日志中，4月动量排名靠前的是天孚通信、中际旭创、新易盛，实际买的是洛阳钼业、招商轮船、铜陵有色、南山铝业。两手预算门槛累计拦截85次候选；这是资金与名义股价造成的筛选，不是新增“价值”信号。
3. **多个风险上限压仓。** 4月目标股票21.52%，7月24.04%；尾部预算等比单纯20%波动目标更紧，宏观70%上限并未成为主要约束。不要把所有低仓位归因于美国通胀。
4. **旧退出可能与选股周期冲突。** v7A7月1日买入TCL科技、7月6—7日卖出，净交易现金流−652.02元；6月1日买入铜陵有色、6月5—8日卖出，−643.87元。说明快进快出亏损存在，但并未单独证明取消止损必然更好。
5. **已见样本被反复修改。** 多次试验均看过本期，不能称新样本外。失败版本保留；不按这一个窗口反复调权重直到赚钱。

## 七、季度版亏损复盘与对账

**整体：**132个交易日收盘记录已取出并独立复算，6月22日峰值102,340.517元至7月17日96,365.812088元，对应最大回撤5.8381%。这是实际持仓在两次调仓之间下跌，不能称“还在被日均线频繁止损”。每日自动退出在此版关闭，损失会保留到季度复核。

**已平仓：**5个完整回合，合计净交易现金流+231.42元，尚不含分红。南山铝业−1,825.25元、洛阳钼业−323.27元、铜陵有色−245.55元；中远海能+1,306.50元、招商轮船+1,318.99元。南山铝业的分红等另计，不能把净交易现金流直接称最终含分红回合盈亏。

**未平仓：**10月8日新买东方盛虹、兖矿能源、中国石油、荣盛石化。四笔买入及费用共25,842.91元，期末市值25,137元，合计−705.91元（费用已含）；中国石油浮盈抵消一部分另外三只的浮亏。这是本期接近归零的重要来源。

**总账：**100,000＋已平仓交易现金流231.42＋未平仓成本与估值差额(−705.91)＋其他现金调整452.087695＝99,977.597695元，净损22.402305元，对应平台舍入−0.02%。全部15笔费用101.37元已在现金流中扣过，不能再扣一次。

日志6条分红按当日持股推算税前合计452.10元，与现金调整差约0.0123元；可能来自展示金额舍入／内部精度，未逐项核实。披露剩余差额，不补造“完全零差”的账本。

**执行约束：**17次提交尝试中2次买单为不足一手的0股订单；季度间不重试。当前成交全部只发生在三个指定日期，未发现额外调仓日。季度内仓位可漂移；固定现金比例并非每日保证。

v6b／v7A／简单v1的成交页面已全量保存，但其完整日收盘净值、最大回撤精确起止与费用外现金调整本轮未全部复原，审计标为部分完成，不能与v8Q的完整132日净值核验混称全部归因通过。

## 八、“拯救方案”：保留低操作，逐项检验

已实施的第一步是季度执行、关闭日线反复退出；本期结果已列出。它降低了交易费用，也使短期跌幅可能保留更久。不是保证赚钱的修复。

后续顺序冻结如下，不为了复原18.19%直接把仓位加满：

| 下一项试验 | 只改变什么 | 如何判定有用／何时否定 |
|---|---|---|
| 资金门槛纠错 | 在季度版上，取消为旧减半卖出保留的“两手＋资产4%”硬门槛，改按真实目标资金、一手、费用判定；不足不买，不自动挤占其他股票 | 检查候选改变、实际现金、行业集中与净收益；若只是加大风险且扣费无改善，否定 |
| 精简仓位预算 | 单独比较仅波动目标与原多风险上限，保持季度日历和选股一致 | 同时看收益、回撤、实际风险占用；用风险匹配基准区分“加仓赚了”与预测改善 |
| 持有期比较 | 季度对半年；先冻结参数，在更多市场阶段按时间向前测试 | 不能只挑本期较好的频率；若换阶段失效，保留简单季度基准 |
| 斐波那契验证 | 在完整候选池做冻结线位事件研究，与同宽度非斐波那契位置对照，不先启用买卖过滤 | 需要足够独立事件及随后1／3个月扣费增量；本期12条精选股观察不能证明反弹优势 |

以上是可证伪的后续研究清单，不是假称已经完成的新收益结果。所有失败与缺失数据保留；不新增实盘或后台交易。
