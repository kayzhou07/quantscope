# 牛熊双操作系统 · RULES V1（预先冻结）

冻结时间：2026-10-20 13:20 (Asia/Shanghai)，冻结人：Lead。**在运行任何 2014—2026 回测之前写定**，用于防止看到结果后倒写规则。之后如需改动，必须新开 V2/V3 并保留失败版本；最终报告必须披露哪些参数是样本内修改。

适用范围：10 万元人民币、只做多、无杠杆、仅主板（sh600/601/603/605、sz000/001/002/003）与创业板（sz300/301），现金不计息；允许长期/全年 100% 现金；不使用 ETF/可转债替代现金。唯一框架限制来自用户。

数据口径：日线；信号只用 ≤T-1 收盘已知数据；默认 T 日开盘执行；停牌、涨跌停、T+1、整手、费用按 `qrun_1416/SPEC_TEAM.md` 统一规则（佣金万2.5最低5元、印花税卖出 0.1%→0.05%@2023-08-28、过户费 0.001%、单边滑点 10bp）。前复权用于信号与总收益估值；真实价格用于整手与涨跌停判断；企业行动以复权序列隐含再投资处理并披露偏差。

## 0. 为什么是"两套操作系统"

- 牛市中最大的风险是**踏空后再追高**与**回撤吞噬复利**；熊市中最大的风险是**抄底过早**与**频繁试错消耗本金**。两者需要不同的目标函数：
  - 牛市 OS：目标是"跟住趋势、让利润奔跑、用移动止损与波动预算控制回撤"，允许 60—95% 股票仓位。
  - 熊市 OS：默认 100% 现金是**主动决策**；目标是"不亏钱、保住购买力、等确认后的修复行情"，只有满足一组严格前置条件才允许 0—40% 试探仓位。
- 状态机负责回答"现在该用哪套 OS"，而不是预测顶底；状态切换有确认期以减少来回打脸。

## 1. 市场状态机（Regime Engine，无未来函数）

输入（全部为 T 日收盘可算，执行发生在 T+1 开盘）：
- 沪深300（sh.000300）日收盘 P；MA20/MA60/MA120/MA250；MA60 斜率=MA60(T)/MA60(T-20)-1；MA250 斜率=MA250(T)/MA250(T-60)-1。
- 回撤：DD60=P/max(P,60日)-1；DD250=P/max(P,250日)-1。
- 波动：VOL20=20日对数收益标准差×√252；VOLPCT=VOL20 在最近750日中的分位。
- 宽度：BR60=当日合格股票池中收盘>各自MA60的比例；BR250=收盘>各自MA250的比例（合格池=主板+创业板、非ST、上市≥250日、有当日行情）。
- 估值（可选，数据具备时）：市场PE中位数分位 PE_PCT（近5年）；缺失时该条件按"不参与"处理并披露。

状态定义（T 日收盘判定，连续 5 个交易日满足才确认切换；CRASH 立即确认）：
- **CRASH**：DD60 ≤ -18%，或（VOLPCT ≥ 0.95 且 DD60 ≤ -10%），或（P < MA250 且 DD250 ≤ -25%）。→ 视为 BEAR 的紧急子状态，T+1 开盘清仓。
- **BEAR**：满足任一且非 CRASH：① P < MA250 且 MA250 斜率 < 0；② DD250 ≤ -20% 且 BR250 < 0.30；③ P < MA120 且 P < MA250 且 DD60 ≤ -10%。
- **BULL**：P > MA250 且 MA250 斜率 > 0 且 P > MA120 且 BR60 ≥ 0.50。
- **NEUTRAL**：其余情况（趋势修复/震荡市）。
状态优先级：CRASH > BEAR > BULL > NEUTRAL（互斥判定顺序）。初始状态 NEUTRAL（2014-01-02 前按 NEUTRAL 处理，避免用 2013 年数据倒推 2014 起点）。

状态 → 目标股票暴露（组合层面，含现金缓冲）：BULL 90%；NEUTRAL 40%；BEAR 0%；CRASH 0%。
状态切换后 T+1 开盘按目标调整；BULL/NEUTRAL 内的个股选择只在月度调仓日进行，熊市OS例外见 §3。

## 2. 牛市操作系统（BULL 状态）

### 2.1 调仓频率与执行
- 每月最后一个交易日收盘计算信号，下一交易日开盘执行；两次调仓之间**不因涨跌做普通换仓**（个股风控退出除外）。
- 采用"先卖后买"资金约束；100 股整手；买入价按开盘价加滑点，卖出价按开盘价减滑点；无法成交的顺序保留至下一交易日（停牌/跌停/涨停）。

### 2.2 合格股票池（每次调仓按 T-1 数据重算）
1. 板块：主板+创业板；剔除科创板、北交所、B股。
2. 剔除 ST/*ST（近60日任一日 isST=1 即剔除；数据缺口按保守处理并披露）；剔除上市不足 250 个交易日；剔除 T-1 停牌。
3. 流动性：过去 60 个交易日日均成交额 ≥ 1.0 亿元；T-1 收盘价 ≥ 2.00 元。
4. 可买性：100 股金额 ≤ 单票预算（否则跳过，不买一手超预算的高价股）。
5. 趋势对齐：T-1 收盘 > MA60，且 MA60 > MA120（个股自身均线）。
6. 非退市整理期（有 out_date 的不买；数据缺失披露）。

### 2.3 选股评分（截面，仅在合格池内排名，预注册）
- 主分：`MOM = P(T-1)/P(T-252) - 1` 剔除最近 21 日（12−1 动量）。
- 辅分：`MOM6 = P(T-1)/P(T-126) - 1` 剔除最近 21 日（6−1 动量）。
- 风险调整：`RVOL = 60日年化波动`；`RAS = MOM / RVOL`（风险调整动量）。
- **V1 综合分 = 0.5×rank(RAS) + 0.3×rank(MOM6) + 0.2×rank(1/RVOL)**；z-score 化后等权合成。
- 不使用财报、行业、情绪、资金流数据（留待 V2 单独检验，先保证可复现与无未来函数）。

### 2.4 持仓与权重
- 默认持有 8 只；每只目标权重 = 目标股票暴露 / 8；权重上限 15%，下限 5%（不足则减少只数至 5 只）。
- 现金缓冲 = 1 - 目标股票暴露；不融资。
- 组合波动预算：若 VOL20 的 750 日分位 ≥ 90%，当月目标股票暴露下调至 60%（只降不升）；其余情况按 §1 状态目标。

### 2.5 个股退出（两次调仓之间允许）
- 移动止损：收盘 ≤ 买入后最高收盘 × 0.85（−15%）→ T+1 开盘尝试卖出；若跌停/停牌无法成交，指令保留。
- 趋势破位：收盘 < MA120 且 MA120 斜率 < 0 → 卖出。
- 若 T-1 触发，T 日开盘执行；卖出后该股不再补回，等下一调仓日重新评估。
- 不做日内交易；同一股票 T 日买入后 T+1 才可卖（T+1 约束）。

### 2.6 组合层面回撤阶梯（本金保护）
以策略自身净值峰值为基准（T 日收盘计算）：
- 回撤 ≥ 10%：下一交易日开盘将股票暴露减半；
- 回撤 ≥ 15%：下一交易日开盘清仓至 0，进入"保护性现金"；
- 保护性现金的解除：仅当状态重新为 BULL 且净值自清仓后回升 ≥ 5%（用收盘确认）时，于下一个调仓日按 50% 目标重建；再一个月后若仍 BULL 恢复 90%。
- 该阶梯为账户级保险丝，不是对用户回撤上限的假设；报告中必须列出触发次数与机会成本。

## 3. 熊市操作系统（BEAR 状态）

### 3.1 默认动作
- BEAR 确认后 T+1 开盘清仓；之后默认 100% 现金，**不因"便宜"或"跌多了"买入**，不设最低仓位与必须建仓期限。
- 现金不自动转为 ETF/可转债/货币基金收益假设（不虚构现金收益）。

### 3.2 允许的"修复试探"（唯一进攻通道，全部条件同时满足）
在 NEUTRAL 状态（熊市已结束、修复确认）下，若同时满足：
1. P > MA20，且 MA20 高于 5 个交易日前的 MA20（短期趋势向上）；
2. DD250 ≥ -25%（下跌已足够深）或 自 60 日低点反弹 ≥ 10%（修复已启动）；
3. BR60 ≥ 0.40（宽度修复）；
4. 估值条件（数据具备时）：市场PE中位数分位 PE_PCT ≤ 0.50；数据缺失则跳过并披露；
5. 非 CRASH 且最近 10 日未触发过 CRASH。
→ 允许最多 30% 股票暴露，持有 3 只最优评分股票（评分同 §2.3），止损放宽至 −12% 移动止损；一旦状态回到 BEAR/CRASH，T+1 开盘清仓。
- 若状态升级为 BULL：按 30% → 60% → 90% 分两次月度调仓加仓（不做一次性满仓）。
- 若连续 2 个月未满足条件：保持 100% 现金，不降标准、不凑交易。

### 3.3 持仓中遭遇熊市的开仓前风控
- 熊市确认时若仍有持仓：T+1 开盘全部卖出（不等止损价）；跌停/停牌保留指令并逐日重试。
- 2015 式流动性危机：连续跌停期间订单保留，实际成交以可成交日为准；报告中单列"未成交天数"与滑点/跳空损失。

## 4. 过渡状态（NEUTRAL）
- 目标股票暴露 40%；持仓 5 只，评分同 §2.3；月度调仓；个股止损 −12% 移动止损；状态转 BEAR 时清仓，转 BULL 时升至 90%（可在下一调仓日一次完成）。
- NEUTRAL 不是"必须交易"状态：若无 5 只合格股票，允许更低仓位甚至全现金。

## 5. 对照与失败版本（必须保留）
- 基准：沪深300 买入持有、创业板指买入持有、50/50 再平衡、全现金；同股票池等权月度再平衡（无风控）。
- 对照策略：①纯牛市 OS（无状态机，始终 90% 敞口）→ 证明状态机是否降低回撤；②纯熊市 OS（始终现金）→ 证明错过行情的成本；③旧式季度 12−1 动量 + 12% 止损（用户在 2015 的 B 版同构规则）→ 与新版对比。
- 每一版记录：规则、参数、运行日期、数据指纹、结果、失败点；不覆盖旧版本。

## 6. 验证与披露纪律
- 报告分段：2014-01—2015-06（牛）、2015-06—2016-01（熊/股灾）、2016-02—2018-01（修复/牛）、2018-01—2019-01（熊）、2019-01—2021-02（牛）、2021-02—2022-12（震荡）、2023-01—2024-02（熊）、2024-02—2024-09（弱修复）、2024-09—2026-10（牛）；另报逐年、全期。
- 每段必须给：收益/最大回撤及区间/月胜率/平均与期末仓位/空仓天数/成交笔数与成交日数/费用/FIFO净损益/同段基准/现金机会成本。
- 参数敏感性：状态机阈值、持仓只数、止损幅度、目标波动各做邻域（±20% 或离散档），报告全表而非挑最优；任何事后调参必须标记为"样本内改进"。
- 稳健性：月度收益 bootstrap、逐段重抽样、最差 20 日、最大回撤修复时长；不得只报全期一条净值。
- 数据缺口：若某字段缺失（ST/停牌/估值/退市），在结果中列明影响方向，不伪造。
- 不声称"已满足用户回撤上限"；用户未指定账户最大可承受回撤百分比。
