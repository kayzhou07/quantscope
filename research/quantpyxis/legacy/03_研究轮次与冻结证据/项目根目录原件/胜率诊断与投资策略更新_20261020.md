# 胜率诊断与投资策略更新

2026-10-20。研究账户10万元，主板及创业板。本文件是本轮现行研究决策；交接包是历史证据，其中旧原则不构成本轮修改禁令。

## 当前结论

平台的23.59%可以用全周期“546个盈利日 / 2315个交易日”复算出来，不能直接解释成“买十次只有两次赚钱”。其中1150日纯现金且收益为零，显著拉低表面比例。风险日盈利比例为46.87%，非零收益日盈利比例为54.82%。持仓时平均盈利与平均亏损幅度相近，盈利优势仍不厚，不能把问题全部归结为统计口径。

当前研究优先级改为：**月度基线 → 修复整手可买候选补位 → 检查市场状态造成的机会损失**。不再默认采用“月度加周度再入场”的组合。增加交易频次、删除高波动限制，均须拿出独立改进证据。

## 二、为什么表面胜率低

### 1. 先查分母：零收益不等于亏损

平台R0页面标注“胜率23.59%”“次胜率53.49%”。本轮已用独立日级计数复算匹配前者；尚未取得完整成交账本来独立核对“次胜率53.49%”，不能将其直接当作已审计的平仓交易胜率。

**全周期新证据：** Q0诊断任务2014-07-01至2023-12-29已完成，409秒。提交代码完整回读一致，仅添加计数；累计收益63.58%、最大回撤14.33%、期末净值163577.0288769元均复现R0。原始日志见`winrate_audit/Q0_completed_logs.txt`，机器统计见`Q0_full_metrics.json`。

|全周期口径|分子 / 分母|结果|
|---|---:|---:|
|全部交易日盈利比例|546 / 2315|23.59%|
|风险日盈利比例|546 / 1165|46.87%|
|仅非零收益日盈利比例|546 / (546+450)|54.82%|
|亏损日|450 / 2315|19.44%|
|零收益日|1319 / 2315|56.98%|
|纯现金且零收益日|1150 / 2315|49.68%|

日级观察包含首日相对10万元的变动，首日零收益也计入；零收益阈值为日净值变动绝对值不超过0.000001元。风险日定义为前一收盘或当日收盘有正股数持仓，退出日仍计风险日，现金退出后的下一日才可能为纯现金日。**三种分母回答不同问题，全部并列保留，不挑最高的一个充当策略胜率。**

风险日中还存在169个零收益日，不能也归为纯现金。需逐日核验持股、停牌、原始估值与账户调整后才能解释，不能先归咎于行情数据错误。若是持股集中且长期停牌，还涉及分散度与退出能力。它列为下一轮账本审计的优先项。

此前先读取R0真实日志的2019-04-24至2023-12-29部分，覆盖1140个收盘净值、1139个相邻日收益，保留如下以展示阶段差异：

|指标|核算结果|
|---|---:|
|盈利日 / 亏损日 / 零收益日|252 / 225 / 662|
|全部日收益的盈利比例|22.12%|
|风险日数量|477|
|风险日盈利比例|52.83%|
|完全现金的收盘日|666|
|最长连续现金收盘区间|2022-01-19至2023-12-29，共473日|

这里的“风险日”定义为前一收盘或本日收盘有股票持仓，包含退出当天；它不是交易次数。零收益日与现金收盘日不要求一一相等。此表是局部证据，不冒充2014年以来完整统计。

局部风险日盈利比例52.83%高于全周期46.87%，不能外推到全部年代。以全周期计数作为本轮总体诊断依据。

### 2. 持仓阶段的优势确实不厚

全周期平均盈利日+634.28元，平均亏损日−628.31元；日平均盈亏幅度比约1.010。盈利日收益金额合计346317.16元，亏损日损失绝对金额合计282740.13元，两者比值为1.225，差额63577.03元与期末净增值一致。

局部2019—2023窗口平均盈利日+685.71元、平均亏损日−693.36元，日盈利因子降至1.108，显示阶段差异。全周期有正收益，但每个盈利日并没有显著大于亏损日的平均收益幅度。这里全部是**日级指标**，不是平仓交易的盈利因子或盈亏比；人民币幅度还受当时净值及仓位影响，须补比例口径。

需同时改善“何时参与、买哪些、承担多少风险、成本消耗”，而非只追求更高胜率。平仓交易的期望值应联合看胜率、平均盈利、平均亏损与费用；通过拖延止损、频繁兑现小盈利来提高胜率，会掩盖尾部亏损。

### 3. 更新慢与空仓恢复是两件事

季度更新可能让标的陈旧或错过恢复窗口；R2的同平台对照给了改月度的初步证据。但现金等待也可能来自市场状态长期禁止买入，单纯提高更新频率未必解决。周度再入场R3反而未优于R2，不能把“更勤交易”当成通用答案。

下一步按日记录：状态禁止买入、未到调仓日、候选不足、整手不可买、订单未成交，各自造成多少现金日和实际暴露缺口。现金是否有益还须与同日可交易基准、后续损失及机会成本比较，不能仅凭错过上涨的事后图形判断。

### 4. 存在一个可复现的选股执行问题

原代码先截取最多10只，再删除超过单股预算、连一手也买不起的股票，没有继续向后补位。10万元账户在25%股票仓位时，每只预分配约2500元；高价候选被删除后，较低排名但可买的股票没有机会进入，最终持股数与分散度可能低于预期。之后按剩余股票数重新分配预算，还可能使实际集中度提高。

S1已改为先在完整排名中检查100股及预估买入费用是否可负担，再按原始排名缓冲保留老持仓，并向后补足至最多10只。没有可买候选时继续留现金。保持原分数、状态、仓位和月度节奏，以隔离这一改动。

本地已通过Python 3.8语法检查、6个整手回归案例及诊断计数检查。**S1尚未完成平台收益检验，修复机械问题不等于已证明收益提高。** 预估费用筛选也不能替代平台开盘价格和资金校验。

“优先保留原排名前20的老持仓”是另一项策略设计，可能减少换手，也可能拖慢替换；目前没有证据直接删除，留作独立对照。

## 三、本轮决策及后续最小实验

1. 删除“季度更新不可变”“周度再入场默认更优”“胜率越高策略越好”三项假定。允许留现金，保留30%历史最大回撤研究筛选线；它不是能保证成交的止损承诺。
2. S0使用R2月度规则并增加诊断计数，先复现84.00% / 11.16%。S1仅加入整手候选补位，与S0同日期、同费用、同状态比较。优先保留简单且稳定的版本。
3. S1之后最多新增一个“删除持仓排名缓冲”的单变量候选，事先冻结规则；只有现金归因或市场状态审计给出证据时，再单立状态替代实验。原R5—R7暂不机械补跑，不进行无上限参数搜索。
4. 每个候选必须交日收益口径、风险日口径、平仓交易口径、零收益日、暴露、持股数、换手、费用、现金原因及未成交原因。优先定位Q0的169个风险零收益日，说明股票、停牌和估值。平仓交易口径预先约定配对方法，并报告期末未平仓浮盈亏，不能选择有利口径。
5. 候选选择要看分年和滚动区间，不能只比2014—2023总收益。一个候选冻结后，再检查2024-09至实际数据末日及2015、2020、2022等冲击段；不可看完最新段再改规则而称其独立验证。
6. 本轮现有历史已被旧策略迭代使用，属于探索和历史外推，不能称为完全未触碰的样本外。未来冻结后的模拟跟踪另记。

## 四、还不能下的结论

尚未独立核验全部历史股票池、退市/ST覆盖、冻结市场状态的原始输入、涨跌停与退出受阻、全部成交费用及交易配对。嵌入状态与原CSV的3448行一致，仅证明搬运一致，不能证明无前视或幸存者偏差。

[平台官方回测说明](https://quant.10jqka.com.cn/view/help/12)说明默认卖出印花税0.1%；本轮尚未证明平台对历史税率变更逐日处理正确。佣金万2.5最低5元、单边10bp滑点和成交量上限是研究设置；缺少真实集合竞价容量时不能称作完全实盘可成交。

最新科技行情尚缺完整正式候选检验。因此R2是当前研究基线，S1是待验证修复，均未晋级实盘。本轮没有真实买卖。
