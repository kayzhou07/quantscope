## 1. 数据来源与口径

| 项目 | 来源 | 说明 |
|---|---|---|
| 原始日线 OHLC / volume / amount / preclose | 新浪财经 KLC 全历史接口（`finance.sina.com.cn/realstock/company/{sym}/hisdata_klc2/klc_kl.js`，官方 JS 解码） | 覆盖上市与已退市股票；volume=股；amount=真实成交额（元） |
| 前复权序列 | 新浪 `qfq.js` 复权因子（Lead 构建） | 文件列 `code,date,open,close,high,low` |
| 复权事件校验 | baostock `query_adjust_factor`（单进程串行；共 61969 条事件 / 4941 只股票） | 用于验证 qfq/raw 比值只在除权除息日跳变 |
| 交易日历 / 股票池 / 指数 | Lead 从 baostock 发布 | calendar 3590 交易日；universe 含退市 |

**已披露字段口径**（不伪造、不插值）：

- `amount`：**真实成交额**（新浪），非代理值。
- `preclose`：新浪参考价（除权除息日）；无参考价时用上一可用收盘价 carry。首日为空。
- `pctchg`：**小数形式**（0.0152 = +1.52%），与 baostock 的百分比口径（1.52）相差 100 倍，使用时注意。
- `isst`：数据源不可得，统一为 0（**不代表真实非 ST**；如需 ST 过滤需另行回填）。
- `turn`：不可得，留空（NaN）。
- `tradestatus`：行存在=1；停牌日整行缺失（无 bar = 停牌/不可交易）。
- qfq 文件只有价格 5 列（code,date,open,close,high,low），无法从 qfq 文件读取 volume —— 量额请用 raw 文件。

### 7b. 非 baostock 事件日跳变的归因（分类脚本 data/scripts/classify_qfq_jumps.py）

对 938 条“不落在 baostock 除权日”的比值跳变逐条归因：

| 项目 | 数量 |
|---|---|
| 非事件日跳变总数 | 938 |
| 其中：当日 raw 收盘-收盘缺口超过涨跌停限制（可确认除权除息） | 269 |
| 其中：±5 个日历日内有 baostock 事件（日期口径差） | 113 |
| 剩余未能用以上解释 | 587 |
| 剩余项中比值变化 中位 / p99 / 最大 | 0.00414867 / 0.159129 / 0.205134 |
| 剩余项中变化 >2% / >5% / >10% | 49 / 16 / 9 |
| 剩余项中 >2% 且 120 天内有 baostock 事件（停牌跨期除权：事件发生在停牌期间，实际价格缺口/复权跳变出现在复牌首日） | 42 / 49 |
| 剩余项中无 120 天内事件（真正未解释，多为低价股 2 位小数价格舍入噪声，中位变化仅 0.00414867） | 105 |

**结论**：全部 >5% 的跳变均可由“除权日发生在停牌期间、复权在实际复牌首日生效”解释（逐条核对样例 000007/000008/000009 的 raw 价格与 baostock 事件一致）；
剩余未解释项为低价股价格舍入噪声量级（中位 0.4%）。没有证据表明复权因子应用错误；引擎若按“比值跳变日”检测公司行动，建议对 <2% 跳变设阈值或结合公告日期。

## 9. 已知缺口与限制

1. **isst 全为 0**（数据源不可得）；任何“剔除 ST”规则在本数据上不可执行，报告中需披露。
2. **turn 缺失**；换手率需另取流通股本计算。
3. **停牌日整行缺失**；回测遇停牌须按“无 bar = 不可成交”处理；已退市股票退市后无 bar，用 universe.out_date 区分。
4. **pctchg 为小数口径**（0.0152=1.52%），与 baostock 百分比口径差 100 倍。
5. **qfq 文件仅 5 列价格**，量额需从 raw 文件读取；qfq 用于信号/收益度量，raw 用于整手/涨跌停/停牌判断。
6. **preclose 口径混合**：除权除息日为新浪参考价，其余为上一可用收盘价 carry。
7. 腾讯源抓取因网络层 WAF 限流（HTTP 501 JS challenge）中止，仅 443 只样本作为独立交叉验证；不影响最终面板。
8. 数据截止 2026-10-19；2026-10-20 当日不完整数据不纳入。
9. **行序未按 (code,date) 排序**（面板按 Lead pipeline 输出顺序，同年内约按日期/代码混合）。引擎读取时应自行 sort 或分组；不影响内容正确性。
