# 原始A60模型的投资与执行规则

版本定位：2026年10月20日《最新投资模式》交接基线A60；主板与创业板、只做多、不融资。它不是后续牛市100%且按月调整的冻结A。

| 模块 | 原始A60规则 |
| --- | --- |
| 仓位预算 | 牛市60%；中性25%；熊市或危机0%；剩余现金按零利息处理 |
| 调仓 | 季度末收盘形成信号，下一交易日开盘撮合；季度外每天检查熊市或危机退出 |
| 选股评分 | 风险调整12-1动量排名50%＋6-1动量排名30%＋低波动排名20% |
| 资格筛选 | 60日平均成交额≥2亿元；价格≥2元；收盘>MA60>MA120；60日年化波动≤55% |
| 组合 | 目标最多10只，目标等权；保留排名缓冲；整手100股，费用与可成交性影响实际持股 |
| 中性处理 | 原规则不在牛转中性时每日强制降至25%；预算主要在季度调仓时生效 |
| 入场节奏 | 退出后通常等待后续季度再入场；本次独立开户未补前季信号，2025年一季度持现金 |

## 评分与状态的可复核解释

12-1动量使用第-22与第-253个复权收盘值；6-1使用第-22与第-127个值。12-1收益除以历史波动率得到风险调整项，各项横截面排名后按50／30／20合成。因子权重是选股评分权重，不是资金仓位。

市场状态由冻结的历史状态文件输入。状态文件、生成器、当时数据版本及信号生效时间必须一起核验，不能仅凭BULL标签或“使用历史文件”就断言已排除未来信息。现有有效数据检查也不等于严格验证上市满250个交易日。

## 成本与实际约束

原始复核采用佣金万2.5、每笔最低5元，卖出印花税按历史日期切换，过户费万0.1，每边10bp滑点；现金收益为0。分红采用复权隐含再投资及部分缺失公司行动推断，不等同真实现金股息到账流水。

原始风险偏好为回撤30%的研究筛选线。它不是保证成交的账户止损，也不是本报告向项目经理承诺的亏损上限。来源 S1。
