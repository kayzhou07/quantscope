# Model rules and version boundaries

## 量寰 QuantVela

日线三态以已完成QQQ收盘P、MA50和MA200计算：P>MA200且MA50>MA200→TQQQ100%；二者均低于MA200→QQQ50%+现金50%；其余→QQQ100%。等于均线归中性。实现于quantvela/rules.py，属于本次按研究说明新增。

独立月度波动率分支：P>MA200时，σ=sd(63个日收益)×√252；L=min(2.5,0.35/σ)。P≤MA200时现金。L≤1使用QQQ+现金；1<L≤2用QQQ与QLD插值；2<L≤2.5用QLD与TQQQ插值。L是指数暴露，不是资金权重和；资金权重始终≤1。月度是否到期由调用方给rebalance_due，不自动每天重平衡。波动率标准差本次采用样本定义ddof=1，是明确实现约定，原材料没有完整计算引擎可逐笔对照。

研究资料包含九个方向与R12探索报告，既有成功/失败/偏差结论均保留，不将合成例子冒充历史回测。多因子股票分支、账户结算/汇率/税费模拟只归档，未凭空新增完整实现。

## 量曜 QuantOrion（前身AlphaBoard）

基础版本筛选代码前缀00/60/30/68；最近两完整交易日涨幅均≥所属规则涨停幅度×0.995。主板10%、创业板/科创板20%，最新成交量<前日成交量。按最新成交量升序；同量按代码是统一接口新增的确定性约定。

variant=baseline；volume_0_7是独立实验参数，不覆盖基线。本次等权目标只表示候选集合配置意图，不沿用原型“前日收盘价买入”的不可能成交承诺。整手数量、停牌/ST、真实涨跌停价、成本与可成交性仍在执行层检查，未新增为隐含筛选规则。

## 量衡 QuantLibra（前身QuantBalance）

资产固定510880.SH、159915.SZ、513100.SH、518880.SH。归一化价格y=P/P0，对时间0…n−1做OLS：M_slope=β×R²。R=P_end/P0−1，D=Σ|P_t/P_(t−1)−1|，M_eff=R×|R|/D；D<1e−12返回0。

两类动量降序排名，以0.5/0.5名次加权，选择最小综合名次。最优效率动量≤0直接空仓，不受冷却约束；当前持仓与最优相同保留；否则持仓不足14自然日且综合名次≤3时保留，其他切换。参数固定，不声称最优。

local_v6_26：默认26个价格点，来自原本地load_csv的LOOKBACK+1。platform_v6_25：25点，是原聚宽策略g.lookback=25的窗口约定；本次仅提供同数学窗口的目标快照，原策略周一14:50触发机制仍需在平台确认。不将两个窗口的业绩混用。并列名次延续固定ETF顺序；非法持仓/未来建仓日由新接口显式拒绝，而旧脚本某些错误可能被容忍。

静态审计器九类规则仍保留在prototypes/quantlibra/auditor。静态命中是核查提示，未命中不等于证明可信。

## 量枢 QuantPyxis

冻结A：m12=x[-22]/x[-253]−1；m6=x[-22]/x[-127]−1；σ=sd(最近61个日收益，ddof=1)×√252。Score=0.5PctRank(m12/σ)+0.3PctRank(m6)+0.2PctRank(1/σ)。百分位采用平均秩；先在非ST、非停牌且有特征的全池排名，再应用资格条件，不改为“合格池先筛后排”。

主板/创业板代码范围沿冻结A；原价≥2元，60日平均成交额≥2亿元，复权收盘>MA60>MA120，σ≤0.55。持仓候选前20保留最多15只，再补到最多15只；按原式单手可负担性≤exposure×NAV/15×1.02剔除，不二次补位。B100%、N30%、E/C0%。

新核心严格要求至少253条完整、对齐、正价格数据；原平台允许部分缺失并前填。该输入边界更严格，属于接口安全约定，不冒充精确平台数据处理复刻。月末调仓、日检查退出、订单重试、不可卖残留仓和实际成交均在原平台脚本，不由快照函数模拟。

冻结状态仅到2026-10-19；不得延长为今天状态。external模式必须提供regime_state、regime_date及来源标识，仅代表调用方注入，不代表新状态模型已验证。

## 组合

w_j=Σ_m α_m w_mj；α_m≥0、Σα_m≤1；仅三个经营模型。默认示例预算各30%，剩余资金保留为现金；这是演示配置，不是优化结论。单资产默认上限25%，超限拒绝；行业检查需外部提供完整行业映射。流动性、跨币种、税费、行业历史版本和成交冲突还须在真实平台进一步核验。
