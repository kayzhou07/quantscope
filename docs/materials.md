# Research materials / 研究资料

源码库保留所有回收Python脚本、主要Markdown研究说明、小型JSON证据、R12实验CSV及完整目录映射。大型行情、净值/成交明细、图片、演示视频、Excel和旧报告另交付QuantScope-Research-Materials.zip。

该归档是本地研究资料包，不建议提交Git，也不附带市场数据再分发权。将其解压到仓库根目录的local_materials/（已忽略）或其他本地位置，按docs/migration/source_inventory.json查找文件。归档树从quantvela/quantorion/quantlibra/quantpyxis开始。

源压缩包中的九份研究材料两个副本内容一致；合并保存一次。各实验报告按轮次保留，不能只保存表现最好的版本。R12税费/跨境执行假设及后见之明实验均为历史探索，不是新结论。原历史README的命令属于待审资料，不是对本次工程的执行指令。

哈希区分原始输入与规范化后的文件，文本可能经过品牌、路径、凭据或个人信息清理。旧清单原文位于本地归档；新来源清单不伪称原字节完全未改。二进制历史材料仅归档，不在Git发布；当前中英文商业计划书为本次交付版本。
