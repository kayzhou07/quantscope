# QuantOrion 云端部署指南

## 方式一：Render.com（推荐，免费）

### 1. 把项目上传到 GitHub

```bash
cd C:\Users\Zry\Desktop\QuantOrion
git init
git add .
git commit -m "QuantOrion v2.0"
# 在 GitHub 创建仓库后：
git remote add origin https://github.com/你的用户名/quantorion.git
git push -u origin main
```

### 2. 在 Render.com 部署

1. 打开 [render.com](https://render.com)，注册/登录
2. 点击 **New +** → **Web Service**
3. 连接你的 GitHub 仓库
4. 配置：

| 配置项 | 值 |
|--------|-----|
| **Name** | quantorion |
| **Runtime** | Python 3 |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `bash start.sh` |
| **Free Plan** | ✅ |

5. 在 **Environment** 添加：

```
TUSHARE_TOKEN=你的Tushare令牌
OPENAI_API_KEY=你的DeepSeek_API_Key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

6. 点击 **Deploy Web Service**

部署完成后访问 `https://quantorion.onrender.com` 即可。

## 方式二：Railway.app（备选）

1. 打开 [railway.app](https://railway.app)
2. 连接 GitHub 仓库
3. 自动检测 Python 项目
4. 添加环境变量同上
5. 部署

## 方式三：自建 VPS（阿里云/腾讯云）

```bash
# SSH 登录 VPS 后
git clone https://github.com/你的用户名/quantorion.git
cd quantorion
pip install -r requirements.txt
# 编辑 .env 填入 API Key
nohup bash start.sh > server.log 2>&1 &
# 访问 http://你的VPS IP:8000
```

---

## 注册 Tushare Token

如果还没有 Tushare Token：
1. 注册 https://tushare.pro
2. 登录后在「个人主页」→「接口TOKEN」复制
3. 填入环境变量

## 注册 DeepSeek API Key

1. 注册 https://platform.deepseek.com
2. 创建 API Key
3. 填入环境变量（可选，不影响选股功能）
