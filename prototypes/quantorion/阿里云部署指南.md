# QuantOrion 阿里云服务器部署指南

## 一、购买服务器（如已有则跳过）

1. 打开 [aliyun.com](https://www.aliyun.com) → 云服务器 ECS
2. 最便宜的配置足够：1核2G，CentOS 7.9 或 Ubuntu 22.04
3. 安全组开放端口：**8000**（或自定义）
4. 获得公网 IP，例如 `47.xxx.xxx.xxx`

## 二、上传代码到服务器

**方法1：直接用 Git（推荐）**

```bash
# 先在 GitHub 创建仓库，推上去
cd C:\Users\Zry\Desktop\QuantOrion
git remote add origin https://github.com/你的用户名/quantorion.git
git branch -M main
git push -u origin main

# SSH 登录服务器后：
git clone https://github.com/你的用户名/quantorion.git
cd quantorion
```

**方法2：scp 上传**

```bash
# 在本机运行（替换 IP）
cd C:\Users\Zry\Desktop
scp -r QuantOrion root@47.xxx.xxx.xxx:/root/
```

## 三、服务器配置（SSH 登录后执行）

```bash
# 1. 安装 Python
sudo apt update && sudo apt install python3 python3-pip -y   # Ubuntu
# 或
sudo yum install python3 python3-pip -y                      # CentOS

# 2. 进入项目目录
cd /root/QuantOrion  # 或 git clone 后的目录

# 3. 安装依赖
pip3 install -r requirements.txt

# 4. 配置 API Key
cat > .env << 'EOF'
TUSHARE_TOKEN=你的Tushare令牌
OPENAI_API_KEY=你的DeepSeek_API_Key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
STRATEGY_MODE=limit_up
EOF

# 5. 后台启动服务
nohup python3 -m uvicorn main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &

# 6. 验证
curl http://localhost:8000/health
# 返回 {"status":"ok"} 即成功
```

## 四、访问

浏览器打开 `http://47.xxx.xxx.xxx:8000`（替换成你的公网IP）

## 五、常用管理命令

```bash
# 查看日志
tail -f /root/QuantOrion/server.log

# 重启服务
pkill -f uvicorn
nohup python3 -m uvicorn main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &

# 查看服务是否在运行
ps aux | grep uvicorn

# 更新代码后重启
cd /root/QuantOrion
git pull
pkill -f uvicorn
nohup python3 -m uvicorn main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &
```

## 六、配置域名（可选）

1. 在阿里云域名解析添加 A 记录 → 指向服务器 IP
2. 安装 Nginx 做反向代理（可选，用80端口）
