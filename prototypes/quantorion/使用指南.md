# QuantOrion 使用指南

## 一、环境准备

### 1. 安装依赖（仅首次）

```bash
cd C:\Users\Zry\Desktop\tod\investment_agent
pip install -r requirements.txt
```

### 2. 配置 API Key

编辑 `.env` 文件，确保以下配置正确：

```
TUSHARE_TOKEN=你的Tushare令牌
OPENAI_API_KEY=你的DeepSeek_API_Key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

> DeepSeek API Key 用于 AI 情绪分析和新闻摘要（可选，不影响选股功能）

## 二、三种使用方式

### 方式1：命令行（最简洁）

```bash
cd C:\Users\Zry\Desktop\tod\investment_agent
python main.py '你目前的资金为500000元，请给出2026年6月5日的投资建议。'
```

输出示例：
```json
{
  "stocks": [
    {"symbol": "600403", "symbol_name": "大有能源", "volume": 67500}
  ],
  "sentiment": {
    "overall_sentiment": "谨慎",
    "market_note": "缩量连板股数量稀少，市场追高意愿不足",
    "stocks": [{"symbol": "600403", "note": "缩量连板，资金博弈为主"}]
  },
  "news": [],
  "stock_news": {"600403": []}

```

> 只需要改资金数额和日期，其他不用变

---

### 方式2：Web 网页（推荐日常使用）

**启动服务：**

```bash
cd C:\Users\Zry\Desktop\tod\investment_agent
python web_ui.py
```

浏览器自动打开 `http://localhost:8000`，界面提供：

- 市场全景面板（上证/深证/创业板/科创50 实时指数 + 涨跌分布 + AI市场简报）
- 财经要闻列表
- 输入资金和日期 → 点「运行策略」→ 显示选股结果
- 回测数据看板（胜率95.2%、收益+3733%等）
- 深色/浅色双模式切换

**其他设备（手机/平板）访问：**

```bash
# 先在本机查看IP
ipconfig   # 找到 IPv4 地址，如 192.168.1.105

# 其他设备浏览器访问
http://192.168.1.105:8000
```

**关闭服务：** 在终端按 `Ctrl + C`

---

### 方式3：API 接口（对接自动化系统）

**启动服务后，通过 HTTP 调用：**

```bash
curl -X POST http://localhost:8000/investment_advice \
  -H "Content-Type: application/json" \
  -d '{"input":"你目前的资金为500000元，请给出2026年6月5日的投资建议。"}'
```

**健康检查：**

```bash
curl http://localhost:8000/health
# 返回 {"status":"ok"}
```

**市场全景数据：**

```bash
curl http://localhost:8000/market_overview
# 返回指数数据 + 涨跌统计 + AI摘要 + 财经新闻
```

## 五、常见问题

| 问题 | 解决方法 |
|------|----------|
| `ModuleNotFoundError` | 运行 `pip install -r requirements.txt` |
| 端口8000被占用 | 修改 `web_ui.py` 中的端口号 |
| 网页打不开 | 检查防火墙是否拦截，确认服务已启动 |
| 输出空数组 `[]` | 当天没有符合条件的缩量连板股，正常现象 |
| Tushare报错 | 检查 `.env` 中的 Token 是否正确 |
| 其他设备连不上 | 确认同一WiFi，检查防火墙放行8000端口 |
| AI情绪不显示 | 检查 DeepSeek API Key 和网络连接 |
