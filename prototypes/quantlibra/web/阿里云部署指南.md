# QuantLibra 阿里云服务器部署指南

> 相比 QuantOrion，本项目**零第三方依赖**（纯 Python 标准库），服务器上只要有 Python3 即可运行，无需 `pip install`，也无需配置 LLM Key。

---

## 一、准备服务器

1. 打开 [aliyun.com](https://www.aliyun.com) → 云服务器 ECS
2. 最便宜配置即可：**1核2G，Ubuntu 22.04**（或 CentOS 7.9）
3. **安全组放行端口 8088**（关键！否则外网访问不到）
4. 记下公网 IP，如 `47.xxx.xxx.xxx`

---

## 二、上传代码

**方法1：scp（最快，免装 git）**

```bash
# 在你本机（Mac）执行，替换 IP
scp -r ~/quant_web root@47.xxx.xxx.xxx:/root/
```

**方法2：Git**

```bash
# 本机推 GitHub，服务器 clone（步骤略，见 QuantOrion 部署指南）
```

---

## 三、服务器配置（SSH 登录后执行）

```bash
# 1. 安装 Python3（Ubuntu 通常已自带，CentOS 用 yum）
sudo apt update && sudo apt install python3 -y

# 2. 进入项目目录
cd /root/quant_web

# 3. 确认零依赖可跑（应该无报错）
python3 -c "import strategies; print('依赖OK')"

# 4. 配置 Tushare token
export TUSHARE_TOKEN=你的Tushare令牌
# 或写入环境文件（推荐，重启不丢）：
echo 'export TUSHARE_TOKEN=你的Tushare令牌' >> ~/.bashrc
source ~/.bashrc
```

---

## 四、启动服务

**方式A：快速启动（临时，重启失效）**

```bash
cd /root/quant_web
nohup python3 -u server.py > server.log 2>&1 &
```

**方式B：systemd 开机自启（推荐，生产级）**

```bash
# 1. 创建服务文件
sudo tee /etc/systemd/system/quantlibra.service > /dev/null << 'EOF'
[Unit]
Description=QuantLibra ETF Rotation Web
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/quant_web
Environment=TUSHARE_TOKEN=你的Tushare令牌
ExecStart=/usr/bin/python3 -u server.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

# 2. 启动并设置开机自启
sudo systemctl daemon-reload
sudo systemctl enable --now quantlibra

# 3. 查看状态
sudo systemctl status quantlibra
```

## 六、常用管理命令

```bash
# 查看日志
tail -f /root/quant_web/server.log          # 方式A
sudo journalctl -u quantlibra -f          # 方式B

# 重启服务
pkill -f server.py                          # 方式A
sudo systemctl restart quantlibra         # 方式B

# 更新代码后重启
cd /root/quant_web && git pull              # 或用 scp 重新上传
sudo systemctl restart quantlibra

# 停止服务
sudo systemctl stop quantlibra
```

## 七、可选进阶

### 1. 绑定域名

阿里云域名解析加 A 记录 → 指向服务器 IP，即可用域名访问。

### 2. Nginx 反向代理 + 80 端口（免输端口号）

```bash
sudo apt install nginx -y
sudo tee /etc/nginx/sites-available/quantlibra > /dev/null << 'EOF'
server {
    listen 80;
    server_name 你的域名.com;

    location / {
        proxy_pass http://127.0.0.1:8088;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
EOF
sudo ln -s /etc/nginx/sites-available/quantlibra /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 3. HTTPS（可选）

用 certbot 申请免费证书：

```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d 你的域名.com
```

## 八、注意事项

1. **Tushare 接口频率**：服务器已内置缓存（信号 30 分钟、回测/基准 1 小时、快讯 60 秒），不会刷爆 Tushare 配额。
2. **安全**：token 只写在服务器环境变量里，不要写进代码或提交到 git。
3. **成本**：1核2G ECS 最便宜档约几十元/月，够用（纯标准库，内存占用极小）。
4. **时区**：快讯时间戳用 `datetime.fromtimestamp` 转本地时区，建议服务器设为北京时间：`sudo timedatectl set-timezone Asia/Shanghai`。
