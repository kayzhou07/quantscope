# 量衡 QuantLibra · 参赛立项书

> 全天候 ETF 轮动策略 × AI 回测可信度审计系统
>
> 参赛方向：**方向二 · 量化投资策略与金融科技工具研发**
> 子选题：**金融科技工具创新**（结合"端到端量化策略"）

---

## 一、项目概述

**量衡**是一套融合「全天候 ETF 轮动策略」与「AI 回测可信度审计」的量化系统。

- **策略层**：双动量轮动（V6）与三策略组合（S123）构建低相关多资产配置，回测年化 14~20%、Calmar 0.81~1.02
- **工具层**：9 条静态规则审计引擎 + LLM 叙事报告，自动识别 9 类回测偏差
- **核心价值**：让回测可信——用可证伪的方法论，把「回测漂亮」与「实盘可复现」区分开

---

## 二、背景与痛点

量化投资最大的坑，是「回测漂亮、实盘打脸」。大量策略回测动辄数百上千个百分点，实盘却无法复现。根源不在行情，而在回测本身的偏差：

| 偏差类型 | 造成的假象 |
|---|---|
| 幸存者偏差 | 选股池"只留下活下来的"，风险被系统性抹掉 |
| 未来函数 | 策略"偷看了答案"，收益含未来信息 |
| 涨跌停成交假象 | "买不到的钱"算进账户，追板收益是虚的 |
| 流动性幻觉 | 小票冲击成本被忽略，容量假设不成立 |
| 过度拟合 | 参数堆积让历史噪声被误认为规律 |

这些偏差有一个共同点：**它们都让回测结果偏向"好看"，而实盘无法复现**。行业里识别这些偏差，长期依赖资深从业者的个人经验，无法自动化、无法量化、无法大规模复用。

---

## 三、解决方案：三大模块

### ① 投资建议网站（web/）

真实数据驱动的网站，把策略从"回测曲线"变成"可操作的每日建议"：

```
选策略（V6/S123）+ 设资金
  ├─ 实时信号（V6 排名 / S123 三腿含 S3 折溢价）
  ├─ 市场情绪温度计（北向资金 + 指数 + 成交额 三因子）
  ├─ 具体股数建议（100 股整数手）
  ├─ 回测曲线（含沪深300基准 + 缩放/悬停）
  └─ 同花顺财经快讯（可跳转 + 分类筛选 + 自动刷新）
```

**技术亮点**：纯 Python 标准库实现，零第三方依赖，服务器只装 python3 即可部署（详见 `web/阿里云部署指南.md`）。

### ② 回测可信度审计工具（auditor/）

针对"回测不可信"这一行业痛点，开发 9 条静态审计规则：

- 自动检测：幸存者偏差 / 涨跌停成交 / 流动性幻觉 / 未来函数 / 过度拟合 / 参数挖掘 / 样本外缺失 / 基准不当 / 成本缺失
- LLM 叙事报告层：把结构化发现转成"影响量级 + 修复优先级"的诊断书
- **一条命令，从策略代码直出审计报告**

### ③ 策略源码（strategies/）

- V6 双动量轮动：斜率动量×效率动量排名加权，周频满仓轮动
- S123 三策略组合：轮动 + 红利 + QDII 套利，三腿相关性 < 0.25

---

## 四、核心创新点

1. **AI 回测可信度审计引擎**：把"回测偏差识别"从经验判断变成可自动化、可量化的工程检查。

2. **LLM 叙事报告层（provider 无关）**：规则引擎产出结构化发现，LLM 负责诊断书化；规则是地基、LLM 是放大器，后端可任意替换 Claude/DeepSeek。

3. **可证伪的回测方法论**：不迷信回测、主动证伪，规则阈值用真实代码 ground truth 校准，而非经验拍定。

4. **低相关多资产轮动架构**：三腿相关性 < 0.25，回撤从 25% 压到 15%，Calmar 从 0.70 到 1.02。

5. **端到端自动化闭环**：策略代码 → 规则审计 → LLM 报告全自动，把"审计"变成可持续流程。

## 五、实证结果（可证伪方法论的落地）

本项目最独特的价值，是**主动证伪自己的成果**（详见 `docs/策略诊断结论.md`）：

| 实证 | 结果 |
|---|---|
| 亲手拆穿 S5 造假 | +4212% 回测 → 幸存者偏差 + 涨停成交 + 流动性幻觉三重叠加 |
| 证伪三个"看似合理"的改进 | 年线开关 / 趋势过滤 / 国债腿 均负贡献，诚实弃用 |
| 三腿低相关验证 | S1-S2-S3 相关性全部 < 0.25 |
| 组合降回撤 | 单策略 25% → 组合 15.3%，Calmar 0.70 → 1.02 |
| 审计规则 ground truth 校准 | 参数堆积阈值来自"267 参数 vs 12 参数"的实测差距 |

审计工具的实证案例：对 S5 小市值策略检出 **11 处高严重度偏差**（见 `docs/S5审计报告_DeepSeek.md`）。

## 七、落地与商业价值

1. **可落地**：网站零依赖、可一键部署（阿里云 ECS + systemd 开机自启），审计工具纯标准库、可嵌入 CI。
2. **可复用**：审计工具不限于本项目——任何量化策略代码都能送进去体检，是一个独立的"量化回测可信度"产品雏形。
3. **有壁垒**：可证伪的方法论 + ground truth 校准的规则阈值，是"别人抄不走的"经验沉淀。

## 八、诚实声明

- 回测数字为简化口径（不复权价 + 简化成本），与聚宽完整回测有差异，已在页面标注；精确值以聚宽为准。
- 网站信号与建议基于历史行情，**不构成投资建议**。
- 我们主动证伪了自己——这是本项目最想传达的态度。
