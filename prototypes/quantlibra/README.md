# 量衡 QuantLibra

> **全天候 ETF 轮动策略 × AI 回测可信度审计系统**
>
> 参赛方向：**方向二 · 量化投资策略与金融科技工具研发**（子选题：金融科技工具创新）

---

## 一句话介绍

**量衡**做两件事：一是构建**全天候 ETF 轮动策略**（双动量轮动 V6 + 三策略组合 S123），二是造了一把**"照妖镜"**——AI 回测可信度审计工具，自动识别幸存者偏差、未来函数、涨跌停成交假象等 9 类回测陷阱，把「回测漂亮」和「实盘可复现」区分开。

---

## 为什么做这个

量化投资最大的坑，是「回测漂亮、实盘打脸」。大量策略回测动辄数百个百分点，实盘却无法复现——根源不在行情，而在回测本身的偏差。本项目用**可证伪的方法论**直面这个问题：不仅做出策略，还做出"确认策略可信"的工具链。

## 三大模块

### ① 投资建议网站（web/）

一个真实数据驱动的网站：选策略（V6/S123）+ 设资金 → 实时信号 + 市场情绪温度计 + 具体股数建议 + 回测曲线（含沪深300基准）+ 同花顺财经快讯（可跳转）。

```bash
cd web
export TUSHARE_TOKEN=你的token
./start.sh          # 一键启动 http://localhost:8088
```

**零第三方依赖**，服务器只装 python3 即可跑，见 `web/阿里云部署指南.md`。

### ② 回测审计工具（auditor/）

9 条静态规则自动检测回测偏差（幸存者偏差 / 涨跌停成交 / 流动性幻觉 / 未来函数 / 过度拟合 / 参数挖掘 / 样本外缺失 / 基准不当 / 成本缺失），LLM 层把结构化发现转成"影响量级 + 修复优先级"的诊断书。

```bash
cd auditor
python3 backtest_auditor.py <策略文件.py>        # 规则审计
DEEPSEEK_API_KEY=xxx python3 llm_report.py <策略文件.py>  # LLM 报告
```

实证案例见 `docs/S5审计报告_DeepSeek.md`（成功拆穿一个 +4212% 的造假策略）。

### ③ 策略源码（strategies/）

- V6 双动量轮动：斜率动量×效率动量排名加权，满仓轮动四个低相关资产
- S123 三策略组合：轮动(50%)+红利(30%)+QDII套利(20%)，三腿相关性 < 0.25
