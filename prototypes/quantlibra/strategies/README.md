## V6 本地信号脚本（signal_v6.py）

纯标准库实现，不依赖聚宽。自动拉 Tushare/腾讯真实行情，输出"今日该持有什么"的清单：

```bash
python3 signal_v6.py --tushare --token 你的token   # Tushare 数据源
python3 signal_v6.py --fetch                        # 腾讯数据源（免费兜底）
python3 signal_v6.py 数据.csv                       # 本地 CSV
```
